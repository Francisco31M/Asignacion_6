Conceptos Fundamentales de la Web

A continuación, exploraremos los conceptos clave que todo desarrollador web debe conocer antes de escribir sus primeras líneas de código.

¿Qué es una página web?

Una página web es un documento digital accesible a través de Internet utilizando un navegador web.
Estos documentos suelen estar estructurados mediante el lenguaje de marcado HTML (HyperText Markup Language) y pueden incluir hipervínculos hacia otros documentos.

¿Cómo funcionan las páginas web?

El funcionamiento de la web se basa en el modelo Cliente-Servidor:
1. El cliente (tu navegador web) realiza una solicitud (solicitud HTTP) a un servidor web a través de una URL.
2. El servidor procesa dicha petición y envía de vuelta los archivos correspondientes (HTML, CSS, imágenes).
3. El navegador interpreta estos archivos y los renderiza visualmente para el usuario final.

Tipos de Páginas Web

Páginas Web Estáticas

Son aquellas cuyos contenidos permanecen fijos. Cada visitante ve exactamente la misma información.
Se construyen utilizando principalmente HTML puro y no requieren bases de datos ni procesamiento en el servidor en tiempo real.

Páginas Web Dinámicas

Son aquellas cuya información cambia constantemente según la interacción del usuario o la actualización de una base de datos.
Un ejemplo claro son las redes sociales o tiendas en línea, donde el contenido mostrado varía según la sesión iniciada.

Diferencia entre Sitio Web y Aplicación Web

A menudo se confunden, pero tienen propósitos distintos:
- Sitio Web: Conjunto de páginas web estáticas o informativas con un objetivo predominantemente de lectura o consulta (ej. noticias, blogs o páginas institucionales).
- Aplicación Web: Un programa de software interactivo que se ejecuta en el navegador web, diseñado para que el usuario realice tareas complejas (ej. editores de documentos en línea, plataformas bancarias, correo electrónico).

Ejemplos y Comparativa de Tipos de Páginas Web

A continuación se resume la clasificación de proyectos web en la industria:

Tipo de Página Web Descripción Ejemplo
Página Estática Muestra contenido fijo predefinido que no cambia según las acciones del usuario. Se sirve exactamente como está guardada. Portafolio profesional personal o sitio de un restaurante local.
Página Dinámica Genera contenido personalizado dinámicamente mediante el procesamiento de bases de datos e interacción del usuario. Plataformas de noticias, blogs interactivos y portales universitarios.
Aplicación Web Herramienta web altamente interactiva enfocada en realizar tareas operativas complejas y gestión de datos. Google Docs, Canva o Banca En Línea.
